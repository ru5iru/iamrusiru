## Implementation boundaries

The live site still serves the previous installed release until the owner restores this XML and updates existing posts/Privacy. Local HTML fixtures do not certify Blogger's compiler, widget merge behavior, indexing or AI citations. Restore and post updates must be verified on Blogger.

The build now generates 72 real WebP variants for 24 images. Their largest variants total 767,326 bytes versus 3,756,323 original bytes (about 80% fewer). These are generated-file measurements, not measured live transfer savings or a Core Web Vitals score. No nonexistent public variant URL is emitted by default.

Primary reference availability is recorded in `primary-sources-2026-11-07.json`; checking a destination does not prove every surrounding factual claim. Public image activation records its own byte/dimension evidence before mutating configuration. Metadata/social content remains server-rendered.

## Validation

Final results are recorded in `release-verification-2026-11-07.json` and `browser-evidence-2026-11-07.json`. The compiled CSS is compared byte-for-byte with the installed-release source snapshot, rather than inferring style preservation from unchanged filenames. The test suite covers XML/widget expressions, native/reusable behavior, metadata, dates, code text, 129 FAQ answers, semantic lists/table, link destinations, Privacy and real generated image dimensions.

Use the new body-aware `npm run verify:blogger:live` after installation. It detects old post bodies and saved widget/Privacy attributes in addition to metadata differences. Deliberate newer native edits need manual reconciliation, not automatic overwriting.
